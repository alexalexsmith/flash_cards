# flash_cards
flashcard tool for creating and using flashcards. Right now it is designed to learn korean

## How to use
run the flash_cards.py python file to run the tool.

drag and drop images into the ui. for each image you will be prompted to write the target laguage word/phrase(required) and the translation(optional)

use the score spin boxes at the top to filter the flash cards based on how many times you get words correct

## Other stuff
You can add your own sounds for correct and incorrect answers by placing .wav files into the resources/sound/correct or incorrect folders
